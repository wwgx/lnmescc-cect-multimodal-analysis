# Locked Model Artifacts

This directory contains non-identifying, aggregate artifacts that support the manuscript's public model availability statement:

- `signature_features_coefficients.xlsx`: score formulas and coefficients for Rad-score, DL-score, and Hab-score (Supplementary Table S2A).
- `model4_coefficients.xlsx`: Model 4 coefficients, odds ratios, and training-set standardization parameters (Supplementary Table S2B).

These artifacts contain no individual-level records. The model should be applied only to data prepared with the same feature definitions and preprocessing described in the manuscript.
